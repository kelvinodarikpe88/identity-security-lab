# Playbook 03 — Risky Sign-In

## Objective

Investigate and respond to high-risk authentication activity.

## Investigation

Review:

- User
- Risk level
- Risk detection
- Source IP
- Location
- Device
- Application
- Authentication method
- Conditional Access result
- MFA result

## Correlation

Correlate identity events with:

- Endpoint telemetry
- Cloud activity
- Email activity
- Privilege changes
- MFA registration
- Password changes

## Containment

Apply the appropriate identity response based on confidence and business impact.

## Documentation

Record the timeline, indicators, investigation findings, response actions, and final classification.
