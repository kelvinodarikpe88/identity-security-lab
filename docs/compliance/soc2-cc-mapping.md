# SOC 2 Common Criteria Mapping

## Purpose

Map security engineering controls and evidence to relevant SOC 2 Common Criteria.

| Control Area | Evidence | Repository |
|---|---|---|
| Access Control | Identity monitoring and response | identity-security-lab |
| Logical Access | Authentication detections | identity-security-lab |
| Security Monitoring | SIEM detections | identity-security-lab |
| Incident Response | Security runbooks | identity-security-lab |
| Change Management | Git commits and pull requests | GitHub |
| Vulnerability Management | Vulnerability findings and remediation | vulnerability-management-lab |

## Evidence Collection

Evidence should include:

- Detection rules
- Investigation records
- Incident response procedures
- Access reviews
- Change history
- Vulnerability remediation records

## Review

Controls should be reviewed periodically and updated when architecture, systems, or regulatory requirements change.
